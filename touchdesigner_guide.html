TouchDesigner：把即時影像接成一個會呼吸的系統

TouchDesigner 是 Derivative 開發的節點式視覺開發環境。你不是照時間軸剪一支影片，而是把影像、聲音、感測器、資料與輸出接成一個持續運行的網路。

Audio Device In聲音輸入
Analyze CHOP提取節奏與數值
Noise TOP產生影像紋理
Window COMP投影／螢幕輸出
Input → process → compose → output：每個方塊都是一個 OP（Operator）
先換一個心智模型五種 OP第一個 patch即時參數小實驗怎麼開始

它不是剪輯軟體，而是一個即時系統

TouchDesigner 的核心單位是節點與連線。節點輸出資料，下一個節點接收、變形或組合；只要輸入變動，整條網路就會在每一幀重新計算。

輸入攝影機、麥克風、MIDI、OSC、感測器或資料。
處理濾鏡、分析、數學運算與 Python 邏輯。
組合混合視覺、3D 場景、UI 與互動規則。
輸出螢幕、投影、LED、錄影或網路串流。

先認識五種常用 OP

OP 是 Operator 的縮寫。初學時不必背完所有節點，先知道資料「長什麼樣子」，就能判斷下一步要接哪一類工具。

TOP

影像與紋理

處理 2D 圖片、影片、攝影機與 GPU 紋理；常用於效果、合成與輸出。

CHOP

時間變化的數值

把音量、滑鼠位置、LFO、感測器數據變成一條或多條數值曲線。

SOP

3D 幾何

建立、修改點、線、面與模型；可送進 3D 渲染流程。

DAT

文字、表格與程式

放 Python、CSV、JSON 與文字資料，是串接資料與控制邏輯的好幫手。

COMP

容器與元件

把網路整理成可重用元件，也能建立 UI、視窗、面板與輸出控制。

MAT

材質與著色

定義 3D 物件表面如何被光照、紋理與 shader 呈現。

第一個 patch：讓聲音推動畫面

這是很適合初學者的練習，因為它把「輸入 → 數值 → 視覺參數」的關係一次串起來。

步驟建立什麼你會看到什麼
1Audio Device In CHOP讀取麥克風或系統音訊。
2Analyze CHOP把波形濃縮成例如音量的單一數值。
3Math CHOP調整數值範圍，避免畫面變化太小或爆掉。
4Noise TOP產生一張不斷變動的雜訊紋理。
5把 CHOP 值 export 到 TOP 的參數音量能控制雜訊的 scale、亮度或位移。

關鍵不是背接法，而是理解「CHOP 的數值可以驅動任何可被數值控制的參數」。這正是聲音反應、互動裝置與即時舞台視覺常見的基本結構。

即時的感覺：參數一變，畫面立刻回應

適合誰？又該怎麼開始？

它特別適合想做現場視覺、互動展覽、音樂演出、沉浸式投影、資料視覺化、控制系統或創意編碼的人。若你的目標是傳統影片剪輯，剪輯軟體會更直接；若你要的是能接訊號、持續變化、現場可操控的畫面，TouchDesigner 很合適。

第一週：從 TOP 開始建立 Movie File In、Noise、Level、Composite，練習影像流程。
第二週：加入 CHOP用 LFO、Keyboard In、Audio Device In 讓參數動起來。
第三週：完成一個小作品把輸入、視覺、控制與輸出整理成可展示的 patch。
持續：學會整理網路命名、註解、封裝成 COMP；可讀性就是大型專案的生命線。
