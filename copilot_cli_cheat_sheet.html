新版進階功能

/branch、/fork建立目前儲存庫的 GitHub fork；兩者為同義指令。
/worktree [TASK]建立平行開發用 Git worktree，保留目前未提交的變更。
/move [TASK]建立新的 worktree，並將未提交的進行中變更一併帶入。
/every、/loop依固定間隔或 cron 排程重複執行提示；需要 experimental mode。
/after [DELAY]在指定延遲後執行一次提示；需要 experimental mode。
/chronicle檢視工作階段歷史、產生 standup、搜尋內容與取得用量建議；需要 experimental mode。
/sidekicks列出、啟用、移除或檢視協作中的專門 AI sidekick agents。
/autopilot、/goal鎖定本次工作階段的具體目標，讓代理持續專注直到完成或變更目標。
/streamer-mode開啟或關閉終端輸出中的敏感值遮罩，例如 API key、token 與憑證。
/voice [on|off|devices]啟用語音輸入、關閉語音輸入，或選擇麥克風裝置。
/mcp registry瀏覽 MCP registry，並安裝新的 MCP server。
/plugin、/skills管理可安裝的外掛與自訂技能，並在異動後重新載入。
