Ubuntu 端的觀察，不是萬用修復咒

nmcli device status
ip link
ip route
# 只有在系統已有該模組、且你知道自己在做什麼時：
sudo modprobe ipheth
# 插線後看最新核心訊息：
dmesg | tail -n 40

介面名稱會因 Ubuntu 版本、硬體與命名規則不同而改變；請以 nmcli 或 ip link 實際看到的名稱為準，不要照抄範例假設是某個固定名稱。

選擇器

USB、Wi‑Fi、藍牙：各自解決哪種情境？

方式適合時候優勢代價／注意事項
USB tethering需要穩定工作、手機也想充電實體連線穩、通常干擾較少需資料線、信任流程與 Linux 驅動辨識
Wi‑Fi hotspot多台裝置、短時間快速加入設定直覺、不必接線耗電與無線干擾較高；注意密碼
藍牙 tethering低頻寬、想省電的輕量工作無需 Wi‑Fi 熱點長開速度通常較慢，配對與設定較繁瑣
工作桌

優先 USB

需要穩定、同時替手機充電時，把它當成一條固定上行線。

臨時會議

優先 Wi‑Fi

要讓多台裝置快速加入時，熱點的擴散能力更重要。

輕量備援

考慮藍牙

傳少量資料可行，但別期待它承擔大下載或視訊會議。

最後一哩

把它當成一條昂貴但好用的備援線

流量不是無限的

系統更新、雲端同步與容器映像下載很容易吃掉行動數據。連上後先暫停不必要的同步，確認電信方案的流量與降速規則。

「信任」不是可忽略的彈窗

只在你信任的 Ubuntu 電腦上允許裝置連線；公共電腦不要為了方便而建立持久信任關係。

常見誤解：有 USB 圖示就等於有網路

不一定。充電、檔案傳輸、裝置配對與網路介面是不同層；依序驗證才能縮小問題。

收尾檢查

確認可連線後，記得在不需要時關閉個人熱點、拔除線材，並觀察是否有背景服務繼續大量下載。
