tmux with Mouse

tmux 預設以鍵盤為主；開啟滑鼠後，仍保有多窗格的效率，並可用點擊、拖曳與滾輪完成直覺操作。這一頁帶你安全啟用、理解行為並驗證設定真的生效。

先理解：滑鼠事件會交給誰？

沒有 tmux 時，終端模擬器直接處理滑鼠。進入 tmux 後，tmux 會先接收事件，再決定是否切換窗格、進入複製模式或把事件送給程式。mouse on 是這個交接規則的開關。

1你移動、點擊或滾動滑鼠
2終端把事件送進 tmux
3tmux 判斷目前窗格與模式
4切窗格、調整大小、捲動或交給程式

最快啟用方式

把下列設定加入 ~/.tmux.conf，重新載入設定檔。此設定會套用到新的與既有的 tmux session。

# ~/.tmux.conf
set -g mouse on

# 在 tmux 裡按 Ctrl-b，再按 :，輸入：
source-file ~/.tmux.conf

也可先在 tmux 命令列暫時測試：Ctrl-b : set -g mouse on。暫時設定在 tmux server 重啟後會消失，因此確認可用後仍應寫入設定檔。

啟用後可以做什麼？

session: work · window: editor
Pane 1
點一下取得焦點
Pane 2
點一下切換到這裡

四個常用操作

  • 點選 pane：把輸入焦點切到被點選的窗格。
  • 拖曳分隔線：改變相鄰 pane 的大小。
  • 滾輪：進入 copy mode 並捲動歷史輸出；按 q 或 Esc 離開。
  • 選取文字：在 copy mode 拖曳選取，放開後 tmux 會複製選取範圍；貼上可用 Ctrl-b ]。

三步驗證

  1. 執行 tmux show-options -g | grep mouse，預期看到 mouse on。
  2. 把目前視窗分成兩個 pane：按 Ctrl-b %，再用滑鼠點另一個 pane；輸入游標應跟著切換。
  3. 輸出幾行文字後用滾輪向上捲；應能看到歷史內容，按 q 回到即時畫面。
tmux show-options -g | grep '^mouse '
# 預期輸出：mouse on

常見陷阱與排除

遠端 SSH：滑鼠設定是在遠端 tmux server 生效；請在遠端主機的 ~/.tmux.conf 設定，而不只是本機。

滾輪沒有捲動

先確認設定載入的對象正確：tmux show-options -g mouse。若你使用 nested tmux（tmux 裡再開 tmux），外層可能先攔截事件；盡量避免巢狀使用或明確選定操作的那一層。

終端不能原生選字

這是預期行為：tmux 把拖曳交給 copy mode。多數終端可按住 Shift 再拖曳，暫時把滑鼠事件交回終端本身；實際快捷鍵依終端模擬器而異。

全螢幕程式行為不同

vim、htop、fzf 等程式會自行使用滑鼠事件。若某個程式沒有反應，先查看它自己的滑鼠設定，而不是關掉 tmux 的 mouse。

最小可複製設定

# ~/.tmux.conf
set -g mouse on
set -g history-limit 50000
setw -g mode-keys vi

# 重新讀取設定
bind r source-file ~/.tmux.conf \; display-message "tmux config reloaded"

設定後按 Ctrl-b r 即可重新載入；需要更多 session、window、pane 快捷鍵時，請搭配 tmux 指令速查表。
