第三個維度。

Three.js 是一套 JavaScript 3D 函式庫。它把 WebGL／WebGPU 的底層圖形能力整理成場景、相機、網格與燈光，讓你能在瀏覽器中建立互動式 3D 體驗。

它替你處理了什麼？

瀏覽器原生已能以 WebGL 或 WebGPU 繪圖，但 API 偏低階。Three.js 提供一致的物件模型與大量現成工具，讓重心回到作品本身。

🧊

3D 場景管理

以物件樹組織模型、群組、材質與動畫，不必自己處理每一個頂點與矩陣。

💡

光影與材質

從基本光源到 PBR 材質、陰影、環境貼圖，建立更有空間感的畫面。

🕹️

互動與擴充

常用的 OrbitControls、GLTFLoader、後製效果與 WebXR 支援都能作為 addons 加入。

一個畫面如何被畫出來？

這五個角色是理解 Three.js 最好的心智模型：把物件放入舞台，用攝影機決定視角，最後交給渲染器輸出到 canvas。

最小可運作範例

以下程式建立一顆旋轉立方體。將它放進 HTML 檔後，以本機伺服器開啟；ES module 通常不適合直接用 file:// 瀏覽。

// 以 CDN 載入 Three.js
import * as THREE from 'https://cdn.jsdelivr.net/npm/three@0.180/build/three.module.js';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 100);
const renderer = new THREE.WebGLRenderer({ antialias: true });

renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);
關鍵觀念

Geometry + Material = Mesh

Geometry 描述「形狀」，Material 描述「表面如何與光互動」。兩者合成 Mesh，才成為場景中可被繪製的物件。

  • 相機預設在原點，物件要移開或相機要後退。
  • 每次畫面更新都要呼叫 renderer.render(scene, camera)。
  • 動畫使用 requestAnimationFrame，每幀調整物件後重繪。

實務上請固定相容的版本；官方文件與 addons 的 import 路徑也應使用同一個 Three.js release。

從零到作品的學習路徑

第一步

幾何與相機

做出 cube、sphere，理解座標軸、PerspectiveCamera 與 renderer 的關係。

第二步

材質、光源、控制器

加入 MeshStandardMaterial、環境光與 OrbitControls，開始用「看起來對」的方式調整畫面。

第三步

模型、效能與互動

以 GLTFLoader 載入 glTF，練習 raycasting 點擊互動，並留意像素比、模型面數與貼圖大小。
