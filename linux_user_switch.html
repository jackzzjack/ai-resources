Identity passport

切換使用者，
不只是換一個名字。

身分、登入環境與授權來源是三張不同的通行證。把 `su`、`su -` 和 `sudo -iu` 放到同一個入口大廳比較。

一眼看懂

你是誰？

帳號與群組決定身分與可用權限。

👤

像誰登入？

HOME、PATH、shell 與 login 設定決定工作情境。

你可以這樣想：切換身分像換工作證；使用 login shell 則像連辦公桌、工具櫃與門禁環境都一起換到目標使用者那一套。

選一張通行證，看看它改變什麼

驗證順序：不要只看 prompt

① 身分

id、whoami

② 工作環境

HOME、PATH、SHELL

③ 工作目錄

pwd 與可讀寫位置

情境對照

方式適合情境新手要注意
su alice短暫換身分較多目前環境可能被保留
su - alice重現目標使用者登入後的環境HOME / PATH 等更接近該使用者
sudo -iu alice管理者依 sudo policy 切換授權來源可受 sudoers 管理與稽核
安全提醒：優先使用個人帳號加上 sudo policy；不要共用帳號或傳遞密碼。
這是一份新手導向的心智模型；涉及正式系統或資料寫入時，請先在可回復的測試環境驗證。
