Terminal recording studio

`tee` 分流一段聲音，
`script` 錄下一整場演出。

兩者都會寫檔，卻在錄不同的東西。把它們放進一間終端機錄音室，就能知道該選哪一支麥克風。

一眼看懂

🎚️ tee：輸出分軌

command 2>&1 | tee build.log

把一段輸出同時送往螢幕與檔案。

🎙️ script：錄整個 session

script -f session.log

錄下終端機互動的過程，而不只是某個命令的輸出。

導播台：你想留下什麼？

錄製範圍比較

問題teescript
主要工作複製 stdin 到螢幕與檔案記錄終端機 session
適合build / 單一 command log重現操作、遠端除錯交接
敏感資訊檢查輸出是否含 token / IP更要避免在錄製中輸入秘密
常見誤解：「都會寫檔」不代表可互換；先決定你要保存的是一段輸出，還是一段操作歷程。
這是一份新手導向的心智模型；涉及正式系統或資料寫入時，請先在可回復的測試環境驗證。
