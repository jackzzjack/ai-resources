先釐清：GPT-5.6 是一個模型家族

OpenAI 於 2026-07-09 發布 GPT-5.6。官方文件將三款一般用途模型分成不同工作層級；API 的 gpt-5.6 alias 會路由到 GPT-5.6 Sol。

共同規格三款皆為 1,050,000 tokens context window、最大輸入 922,000 tokens、最多輸出 128,000 tokens，knowledge cutoff 為 2026-02-16。
共同能力文字與圖片輸入、文字輸出、reasoning tokens、streaming、function calling 與 structured outputs；不支援原生音訊／影片輸入，也不支援 fine-tuning。
名稱邊界：GPT-6 Astra 也是 OpenAI 於 2026-09-03 發布的正式模型；本頁刻意聚焦 GPT-5.6 家族，不把兩者混為同一代。

四個不能漏看的限制

超長提示有不同費率

官方文件寫明：輸入超過 272K tokens 時，整個 request 的 input／cache write 為 2 倍、output 為 1.5 倍價格。

工具可能另外計費

搜尋與 computer use 等工具可能按呼叫計費；單看 token 價格不是完整帳單。

規格不等於任務成績

官方定位與 context 長度不能取代實際 eval。請用自己的資料、完成定義與風險條件做對照測試。

能力提高也要更嚴謹

官方系統卡將三款模型的資安與生物／化學能力評為 High，並提醒代理式任務仍須限制權限、要求確認與檢查實際動作。
